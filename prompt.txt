PROMPT PARA EL PROYECTO "El Libro Completo de Enoc" (Next.js) — ESTADO ACTUAL
================================================================================

Resumen
-------
Lector web del libro "El Libro Completo de Enoc" con texto de 193 capítulos,
índice navegable por libro/capítulo, lectura por voz (Web Speech API) con voz
masculina en español y scroll automático animado (framer-motion) mientras se
lee. El proyecto YA ESTÁ CONSTRUIDO y funcional; este documento describe el
estado actual y sirve de referencia para continuar el desarrollo. Stack:
Next.js 16 (App Router, TypeScript, Turbopack) + Tailwind v4 + shadcn
(Base UI) + framer-motion.

  * public\data\index.json                           (índice global)
  * public\data\<sectionId>.json                     (13 secciones)
    acerca, evidencia-gigantes, gigantes-resumen, libro-1..5, libro-gigantes,

Reglas de segmentación:
  * Encabezados en MAYÚSCULAS que contengan "CAPÍTULO"/"Resumen"/"Análisis"
    -> nuevo capítulo. Encabezados partidos entre páginas se fusionan.
  * Unidades (versículos): números secuenciales (n == last+1 o gap <= 3) con
    primera letra mayúscula; si no, texto corrido (n = null).
  * Resultado verificado: 192 páginas de texto, 13 secciones, 1312 unidades.

Esquema de public/data/index.json:
  { "title": string, "subtitle": string,
    "sections": [ { "id": string, "kind": "front"|"book"|"extra",
      "num"?: number, "title": string, "page": number,
      "chapters": [ { "id": string, "num"?: number, "title": string,
        "subtitle"?: string, "page"?: number, "count": number } ] } ] }
  Subtítulo: "Versión estándar — Dr. Jay Winter"

Esquema de public/data/<sectionId>.json:
  { "id": string, "kind": ..., "title": string,
    "chapters": [ { ...ChapterMeta, "units": [ { "n": number|null,
      "text": string, "page": number } ] } ] }

5) ESPECIFICACIÓN DE FUNCIONALIDAD (ESTADO ACTUAL)
--------------------------------------------------
A) use-speech.ts (Web Speech API, cola de utterances):
   - Carga de voces: getVoices() + voiceschanged + polling 250 ms (máx 4 s);
     rankVoices() (es +100, es-ES +10, masculino +50, femenino -60,
     localService +5).
   - pickDefaultVoice(): voz masculina española (Sebastian, Alvaro, Alonso,
     Jorge, Miguel, Raul, Diego, David, Guy, Roger, Andrew); fallback
     cualquier es-ES. En Windows: "Microsoft Sebastian Desktop" (es-ES),
     "Microsoft Alvaro/Alonso" (es-US), "Microsoft Jorge" (es-MX).
   - speak(chunks, callbacks, startIndex): cancel() + arranque tras 60 ms;
     utterances encadenados vía onend/onerror con epoch incrementado.
   - callbacks: onChunk(i) (resaltar unidad + progreso) y onComplete()
     (avanzar al siguiente capítulo con autoplay).
   - pause()/resume()/stop()/jump(chunkIndex, shouldPlay=true).
   - Keep-alive: setInterval 8 s que llama resume() si playing && !paused.
   - rate/voice leídos de refs; clamp rate [0.5, 3]; fallback lang "es-ES".
   - Devuelve { supported, voices, playing, paused, index, speak, pause,
     resume, stop, jump }.

B) use-smooth-scroll.ts (scroll animado con framer-motion):
   - useSmoothScroll<T>(axis: "y"|"x") => { ref, scrollTo(target, dur),
     scrollToElement(el, dur), centerElement(el, dur), stop }.
   - Usa useMotionValue + animate(position, target, {duration, ease
     [0.22,1,0.36,1]}) y sincroniza el scrollTop/scrollLeft real.
   - Cancela en wheel/touchstart/pointerdown; limita al máximo del contenedor.
   - scrollToElement centra el elemento al 22% de la altura; centerElement
     centra horizontalmente.
   - stop() cancela una animación en curso (añadido para page-viewer).

C) reader-view.tsx:
   - Columna max-w-3xl con cabecera animada por capítulo (sección, título,
     subtítulo, "N unidades · página X").
   - Portada del libro: si chapter.page === 1, muestra
     <img src="/paginas/pagina_001.png"> a ancho completo con borde/sombra
     entre la cabecera y las unidades.
   - Unidades: div clickeable data-unit="i"; activa con bg-accent + barra
     vertical animada (layoutId "active-unit-bar"), número de versículo en
     primaria, texto con clase `.reading` (serif justificado).
   - Auto-scroll suave a la unidad activa (scrollToElement a ~22%).
   - Estado de carga con skeleton.

D) nav-sidebar.tsx:
